    The extension reads newly visible article text, skips unchanged content, and adds small removable stickers. Its corner HUD reflects recent visible observations. Sound starts only when you enable it.

    1. Download and unzip the extension.
    2. Open chrome://extensions (or edge://extensions), enable Developer mode, then choose Load unpacked.
    3. Select the unpacked folder. Open an article, click KitiKat, then Start on this tab.

    Chrome desktop tested. Edge targeted but not separately verified. The browser demo is the original screen-sharing detector; the extension carries all four weather dimensions.
