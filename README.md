# KITIKAT — Symbolic Weather Monitor

Public static landing page, local browser OCR demo, and unpacked browser extension.

Live: https://tomislavrupic.github.io/kitikat-symbolic-weather/

Everything is a static asset. No remote classification, application telemetry or accounts. The text classifier is an experimental hand-authored English rules engine, not a trained language model. GitHub receives normal asset requests; analyzed text and screen frames stay in the browser.

The screen-sharing demo requires explicit Start and the browser picker. Choose the article tab and check Capture Source. The four-channel extension is downloaded and loaded unpacked using the instructions on the site.
